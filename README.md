# KasKita — Keuangan Keluarga (by ylowstone)

Aplikasi Android ringan untuk mencatat arus keluar-masuk uang harian keluarga beserta kalkulasi **rata-rata per Hari, per Minggu, per Bulan, dan per Tahun**.

## Fitur Utama
- **UI Bersih Gaya Apple Music:** Tema **Gelap OLED**, **Cerah**, dan **Ikuti Sistem** otomatis + 4 pilihan Warna Khas (*Apple Rose, Cobalt Blue, Emerald, Warm Amber*).
- **Kompatibel Android 10 – Android 17:** `minSdk = 29` (Android 10) sampai `compileSdk = 37` & `targetSdk = 37` (Android 17), mendukung *Edge-to-Edge*, *Adaptive Icon*, dan *Monochrome Themed Icon* Google Pixel.
- **100% Offline & Tanpa Login:** Tidak butuh internet atau akun. Dilengkapi **Export Excel (CSV)** dan **Backup/Restore JSON** langsung lewat Android Storage Access Framework.
- **Splash Screen Halus & Watermark:** Animasi awal ringan tanpa *white flash* + kredit halus `by ylowstone`.

## Cara Mendapatkan File .apk Otomatis
Repositori ini (`https://github.com/liveforever24/kaskita`) sudah dilengkapi **GitHub Actions**:
1. Buka tab **Actions** di halaman GitHub repositori ini.
2. Pilih workflow **Build KasKita Android APK** yang sudah bercentang hijau.
3. Unduh artifact **KasKita-Android-APK**, ekstrak, lalu kirim `KasKita-v1.0.0-by-ylowstone.apk` ke HP keluarga via WhatsApp.
